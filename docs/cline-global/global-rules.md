GLOBAL RULES (any repo)
- Edit only files inside the open folder.
- Never create, read or print secret files: .env, *.pem, *.key, token files. Never write a real password, key or token into any file.
- You cannot run commands. Never write tool-call JSON as text.
- Never delete or rename a folder without asking.
- Do not add external services, analytics or tracking code.
- Change the least possible. Do not reformat files.
- If unsure, say unknown. Ask at most one question.
- End with: (1) files changed, (2) a short suggested commit message.
